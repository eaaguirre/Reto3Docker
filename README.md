# Reto 3 - Node.js + Docker + Seguridad + CI/CD 🚀

Este proyecto es una API básica en Node.js usando Express, que cumple con los requerimientos del Reto 3:

- API funcional y dockerizada
- Linter sin errores (revisable con extensiones)
- Pruebas unitarias con Jest + Supertest
- Análisis de vulnerabilidades con Trivy
- GitHub Actions para CI/CD en Pull Request
- Buenas prácticas de estructura y documentación

---

## 📦 Requisitos

- Node.js v20.x
- npm
- Docker
- Trivy
- GitHub

---
